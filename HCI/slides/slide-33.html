Manipulating

The slide uses motion-based gaming to demonstrate manipulation.

Lecture segment

Manipulation means interacting directly with objects rather than giving abstract commands.

Examples include:

  • dragging a file;
  • resizing a window;
  • rotating an image;
  • pinching to zoom;
  • moving an object in a game.

Compare:

“Increase image scale to 150%.”

with simply pinching outward.

The second feels like manipulating the object itself.

Professional application

Direct manipulation is particularly powerful when the task is:

  • spatial;
  • visual;
  • creative;
  • physical.

Examples include:

  • CAD;
  • graphic design;
  • maps;
  • video editing;
  • games.

The user receives immediate visual feedback, making the relationship between action and result easy to understand.
