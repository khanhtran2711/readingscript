Conceptual Model

This reminds us that there is rarely only one understanding of a system.

Developers tend to understand systems through architecture:

database → API → service → interface.

Users normally do not care.

A user may understand Google Drive as:

“The place where my files live.”

Technically that is incomplete, but it may be entirely sufficient for successful interaction.

Key HCI lesson

We do not need users to understand the implementation.

We need them to have a mental model that is sufficiently accurate to achieve their goals.

An interface that requires users to understand technical implementation details has probably exposed unnecessary complexity.
