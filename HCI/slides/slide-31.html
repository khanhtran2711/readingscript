Instructing

The slide illustrates instructing using a vending machine.

Lecture segment

In instructing, users tell the system what they want it to do.

For example:

Press B7.

The system interprets the instruction and performs the action.

Digital examples include:

  • clicking Print;
  • selecting Delete;
  • choosing a command from a menu;
  • entering a keyboard shortcut.

When is instructing effective?

Usually when:

  • actions are clearly defined;
  • tasks repeat;
  • users know what outcome they want.

For example, in file management:

Copy, rename, delete, move.

These are clear instructions.

Design concern

The user must understand available commands.

If commands are hidden or badly labelled, instructing becomes difficult.
