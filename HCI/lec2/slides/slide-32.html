Conversing

The slide illustrates a conversational interaction using a ticket machine.

Lecture segment

Conversational interaction makes the system behave more like an exchange between two parties.

The machine asks:

“Where are you travelling?”

The user responds.

Then:

“Single or return?”

And so on.

Modern conversational systems make this even more obvious:

“Book me a flight to Paris next Tuesday.”

Benefits

Conversational interaction can reduce the need to understand complex interface structures.

But there is a danger

A conversational interface creates an expectation that the system understands language.

When the system repeatedly responds:

“Sorry, I didn't understand that.”

the conversational metaphor collapses.

Therefore conversation works best when the system can manage both expected and unexpected user input appropriately.
