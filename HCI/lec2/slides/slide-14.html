Conceptual Model: High-Level Description

This is a citation from Johnson and Henderson's definition:

a conceptual model is a high-level description of how a system is organised and operates.

Lecture segment

The important phrase is high-level.

A conceptual model does not specify:

  • the exact font size;
  • hexadecimal colour;
  • 12-pixel versus 16-pixel padding.

Instead it concerns questions such as:

  • What objects exist?
  • What can users do with them?
  • How are objects related?
  • What happens when an action occurs?
