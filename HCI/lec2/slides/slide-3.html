What is Interaction Design?

Lecture segment

Notice the word behaviour.

Interaction design is not only concerned with what something looks like. It is concerned with what happens when users interact with it.

Consider a simple button.

A visual designer may consider:

  • colour,
  • typography,
  • border radius,
  • spacing.

An interaction designer additionally asks:

  • What happens when the user taps it?
  • Can it be tapped twice?
  • What happens while processing?
  • What happens if processing fails?
  • Does the user receive confirmation?
  • Can the action be undone?
