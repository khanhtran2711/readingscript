Understanding and Conceptualising Interaction

Lecture segment

Today we move from simply asking “Is this interface easy to use?” to a more fundamental HCI question:

How does the user believe this system works?

This is important because interface design is not simply about choosing colours, buttons, menus, or typography. Before designing the visible interface, we need to decide what kind of interaction we want users to have with the system.

For example, imagine that we are designing a food-delivery application. Before we decide whether the Order button should be green or blue, we need to answer more fundamental questions:

  • How does a customer find food?
  • Is food organised by restaurant, category, location, or recommendation?
  • What does adding food to an order mean?
  • Can the customer modify an order?
  • At what point is the order confirmed?
  • What feedback does the system provide?

These decisions form the basis of the user's understanding of the system.

This week therefore focuses heavily on conceptual models, mental models, metaphors, interaction types, and cognitive friction.
