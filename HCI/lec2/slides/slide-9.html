Slide 9

Conceptualising a Design Idea: Why?

The slide uses an intentionally uncomfortable-looking pair of boots.

Lecture segment

This visual is useful because something can technically function and still have a poor conceptual design.

The question arises:

Should we design it this way simply because we can?

Software development teams frequently make this same mistake.

A programmer might say:

“Technically, the system supports this feature.”

But from an HCI (Human-Computer Interaction) perspective, the question is:

“Will anyone understand how to use it?”

The conceptualization process compels us to consider user understanding before implementing detailed interface elements.

Class discussion

Show the image briefly and ask:

“What do you believe these shoes are supposed to help the user accomplish?”

The difficulty students experience interpreting the object is itself a lesson: if the object's purpose or operation conflicts with expectations, interaction becomes difficult.
