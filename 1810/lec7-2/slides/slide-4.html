Approximately 7 minutes

“When writing hypotheses mathematically, H₀ and Hₐ must be *opposites*. The type of inequality symbol you use — like ≥, ≤, =, <, >, or ≠ — tells you which kind of test you’re performing. For example: - Left-tailed test uses `<` - Right-tailed test uses `>` - Two-tailed test uses `≠` Null hypotheses usually include symbols like ≥, ≤, or = While the alternative hypothesis includes <, >, or ≠. The equality belongs to H₀ because hypothesis testing needs a precise reference value to construct the sampling distribution and calculate the p-value.

Think of H₀ as “nothing unusual is happening.”
